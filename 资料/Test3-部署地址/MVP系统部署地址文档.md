## 三、系统功能入口

| 功能 | 说明 |
|---|---|
| 员工端对话（`/chat`） | SSE 流式问答，Agent 5 轮工具循环（查规程 / 影响面 / 登记事件 / 通知 / 转人工） |
| 管理后台（`/admin`） | 变更事件 / 通知任务 / 转人工记录 / 审核门日志 / 知识库文档 |
| 后台事件页（`/admin/events`） | 变更事件列表 |

### 核心业务能力（与需求方案一致）

- **完成口径**：以「资源可用回执」而非「通知发出」判定闭环完成（P0-①）
- **转人工四要素**：触发原因 / 接手人 / 确认时间 / 业务编号+版本，缺一不可（P0-②）
- **不可逆红线**：退款/改签/赔偿/发车/入住/旅客资料，系统不自主执行（G4）
- **三处人工审核点**：G1 口径签发 / G3 通知下发前确认 / G4 不可逆审批
- **超时升级**：通知 30/60 分钟未回执两级升级

## 四、本地运行方式（备选）

后端系统可本地运行：

```bash
cd 资料/src2-MVP系统
python -m pip install -r requirements.txt   # 首次安装依赖
python run.py --port 8000                   # 启动 Web（默认 127.0.0.1:8000）
```

控制台演示与评测（零依赖）：

```bash
python quickstart.py        # 3 场景控制台演示
python evals/run_eval.py    # 30 条评测（当前 30/30）
```

## 五、真实执行测试

系统自带可真实执行的 HTTP 测试脚本（对标报销助手 `run_tests.py`）：

```bash
# 先启动隔离实例（用独立端口，避免污染正式数据）
python run.py --port 8130 --no-browser

# 另开终端跑五类测试用例（正常/边界/对抗/权限/故障）
python Test/_scripts/run_tests.py --base http://127.0.0.1:8130
```
