## 三档报价速览

| 档位 | 定位 | 人天 | 报价（含税） |
|---|---|---|---|
| 低档 · 基础闭环版 | 先跑通通知回执闭环，验证价值 | 46 | 57,500 元 |
| 中档 · 标准交付版 | 完整覆盖全部验收指标（推荐） | 94 | 117,500 元 |
| 高档 · 增强智能版 | 标准版 + 自动影响面推荐 + 多事件源 | 122 | 152,500 元 |

## 核心量化口径

- 通知遗漏率：14% → 低于 2%（目标）
- 异常确认耗时：80 分钟 → 20 分钟（目标）
- 业务规模：90 团/月 · 7 家服务商/团
- 试点范围：10 个团 · 覆盖率 100%

## 重要声明

本资料依据《行知旅行 · 业务需求发现报告》V1.0（2026-10-23）编制，访谈基于合成场景，6 项候选需求均为待验证假设，不作为验收结论。行业分析引自公开资料，仅作方向性参照。所有指标口径须在试点前由运营经理书面签发。
