# 行知旅行访谈证据要点

> 版本 V1.0 ｜ 来源：六人访谈（36 条证据 f00–f55）

本文件是访谈证据的结构化要点，供问答检索引用。

## 一、核心痛点

- 行程变更后，酒店、车队、游客会收到不同版本的时间信息（证据 f00）。
- 导游只能逐个打电话人工确认，异常确认耗时 80 分钟（证据 f00）。
- 通知遗漏率 14%，目标降至 2%（证据 f00）。
- 关键变更确认覆盖率目标 100%（证据 f02）。

## 二、根因归因

- 完成口径两套并存：服务商按「发通知」算完成，导游按「确认资源可用」算完成（证据 f50、f53）。
- 多版本并存：改一版行程即另发一次，无统一版本主键（证据 f10）。
- 影响面靠人工估算：旅客人数、名单与服务订单缺稳定关联（证据 f31）。

## 三、审核门与权限

- 五道审核门 G1–G5（证据 f04、f41）。
- 审批清单未成文，否决权与拍板人未核实，存在越权与借用账号风险（证据 f41）。

## 四、范围红线

- 不自主退款、不自主改签、不承诺赔偿（证据 f52）。
- 不可逆动作一律强制人工审批（证据 f41、f52）。

## 五、留存与审计

- 记录分散在三系统 + 便签 + 群消息，无法审计重建（证据 f45、f54）。
- 全链路留痕不记录账号口令与不必要个人信息（证据 f45）。
