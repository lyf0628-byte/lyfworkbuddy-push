```bash

cd 资料/src2-MVP系统
python run.py --port 8130 --no-browser

# 2. 跑测试
python Test/_scripts/run_tests.py --base http://127.0.0.1:8130
```

## 测试原则

1. 全部用例通过真实 HTTP 请求打隔离实例，不 mock；
2. 如实记录系统现状，已知薄弱点以 `note` 标注（不粉饰）；
3. 业务断言紧扣「口径 / 红线 / 审核门」三要素，与需求方案一致。

## 已知薄弱点（如实记录）

- **非法 JSON 请求体返回 500**（TC-F-04）：`app/main.py` 全局异常处理器兜底返回 500，生产建议改为 400/422。
- **请求体长度无上限**：`/api/chat` 未限制 message 长度，超长输入会进入检索流程（生产建议加长度校验）。
- **鉴权依赖重定向**：未登录访问 `/chat`、`/admin` 返回 307 重定向，而非 401/403 状态码。
